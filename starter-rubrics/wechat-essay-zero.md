# Starter Rubric：微信公众号文章 — v0 cold-start 占位

**这是给完全没数据的新作者用的占位 rubric。**它会打错。**前 5 篇预测精度大概 ±50%——这是 cold-start 的数学事实，不是 rubric 失败**。

跑完 5 篇（每篇都走完 `/cheat-essay-predict` → 发布 → `/cheat-essay-retro` 闭环）之后，你会有第一份个人校准数据，可以提议第一次 `/cheat-essay-bump` 升级到 v1（或直接采用 [wechat-essay.md](wechat-essay.md) 的完整版作为起点重新校准权重）。

---

## 适用范围（**必读 — 用错形态会失效**）

本 rubric 设计目标是**议题 / 观点类深度长图文**（1k-5k 字）：

✅ **完全适用**：议题评论 / 时事观点 / 行业分析 / 个人深度随笔 / 知识科普长文 / 现象级议题讨论

⚠️ **部分适用**（rubric 分数能给但解释力打折）：
- **教程实操类**（"5 个 X 玩法"/"手把手教你 Y"）——核心维度是「实操可复用度」「场景刚需度」「完成度」，本 rubric 不抓；IE 维度对教程文会失真，建议标 N/A
- **新闻热点类**（"刚刚，X 发布"/"重磅消息"）——传播 70% 来自时效 + 账号粉丝盘 + 推荐流加权，本 rubric 抓不到外部因素，composite 分数和实际表现无强相关

❌ **不适用**：
- **短消息 / 卡片型**（< 500 字的产品更新 / 推文转载 / 单段引用）——无独立标题、无开头铺垫、无结尾出口，7 维全部错配
- **图集 / 漫画 / 视频为主，文字辅助**——内容主体不在文字层
- **纯营销 / 软文 / 带货**——目的是转化不是传播，应该用转化漏斗 rubric 而非内容传播 rubric

**你的文章如果落在「部分适用」或「不适用」范围**：仍然可以走完整循环（rubric 至少强迫你做盲预测纪律），但**复盘时不要根据 composite 分数下"内容质量好/差"的结论**——它没说这件事。

未来版本路线（社区贡献）：
- v0.2 候选：教程实操型独立 rubric（增加实操维度，删 IE / EG）
- v0.3 候选：新闻热点型独立 rubric（增加 HM 热点借势力维度）

## v0 综合分公式（**等权占位**）

```
composite = (TH + OP + IE + EG + SR + QD + AE) / 7 × 2.0
```

每个维度 0-5 整数分。综合分范围 0-10。

**为什么等权而不是差异化权重**：
- 你**没有数据**支持任何特定权重
- 用任何"通用经验"权重起步会让你以为这些权重是普世的——它们不是，公众号每个垂类的真实权重都不一样（财经类 vs 情感类 vs 职场类 vs 时评类的 TH/IE 权重差很大）
- 等权能让你在数据出来之前对每个维度都给"中立的关注"
- 第 5 篇之后你的复盘数据会告诉你哪些维度真的预测了你的账号的传播

## 7 个维度

公众号 2025 算法健康度权重（**这是平台层面的权重，不是 rubric 内部权重**）：打开率 40% / 互动率 30% / 分享率 20% / 完读率 10%。下面 7 个维度按"对哪个平台权重贡献最大"对齐设计。

### TH — Title Hook（标题钩子力）
*看到标题（搜一搜 / 推荐流 / 订阅卡片）想不想点？影响打开率（40% 权重）。*

- **0** — 描述性流水标题（"今天发生了一件事"）
- **3** — 有具体信息密度，但平淡（"我和父亲的一次对话"）
- **5** — 指名道姓的痛点 / 反直觉断言 / 不打开就好奇死你的钩子

注意：好标题不等于"标题党"。好钩子是承诺一个具体的信息收益，文章里兑现；标题党是承诺收益但不兑现。后者会摧毁完读率和涨粉。

### OP — Opening Pull（开头留人）
*前 200 字（约 3-5 段）有没有按住读者？影响完读率前段（10% 权重）。*

- **0** — 三段铺垫还没进正题（"今天我想跟大家聊聊..." × 3 段）
- **3** — 第二段开始进入正题，但前面有"今日金句"之类的铺垫
- **5** — 第一段就有钩子 / 反差 / 具体场景，让读者忘记自己在「读公众号」

公众号的"上滑就走"是无成本的。开头不抓人 = 后面所有维度白搭。

### IE — Issue Edge（议题锋度）
*角度是不是常见到平庸，或锋利到值得「在看」？影响互动率（30% 权重）。*

- **0** — 常识复读（"努力就有回报"）
- **3** — 有自己的切入但角度大众化（"我觉得职场要..."）
- **5** — 反主流共识 / 命名了读者意识到但说不出的现象 / 把熟悉的东西陌生化

「在看」按钮是社交风险投资——读者只在「想让朋友知道我在思考这个」时才点。IE 是这个动作的核心驱动。

### EG — Emotional Granularity（情感颗粒）
*有没有具体到读者「啊我也是」的细节？影响分享率（20% 权重）。*

- **0** — 抽象情绪词堆砌（"焦虑"、"内耗"、"破防"）
- **3** — 一两个具体场景但快速带过
- **5** — 具体到颗粒度极细（具体的物品、时间、对话），细到读者觉得「这是写我的吗？」

分享到朋友圈本质是「这文字代表我」。颗粒度不足 = 没有代入感 = 没人转发。

### SR — Structural Rhythm（结构节奏）
*小标题、加粗、段落呼吸如何？影响完读率全程（10% 权重底层）。*

- **0** — 整篇没有小标题 / 加粗 / 列表，3000 字砌墙
- **3** — 有小标题但分段密度不均（前面密、后面散）
- **5** — 节奏可视化：小标题清晰 / 关键信息加粗 / 长段拆短 / 视觉留白

手机阅读场景下，结构 = 完读率。砌墙 = 跳出。

### QD — Quote Density（金句密度）
*是否有可截图分享到朋友圈 / 微信群的句子？影响朋友圈打开率间接驱动二次传播。*

- **0** — 全文找不到截图点（叙事流水）
- **3** — 全文有 1 句能独立站立
- **5** — 每千字 ≥2 个截图句，分布在不同段位

公众号朋友圈传播的标准物是「截图 + 短评」。没有可截图的句子 = 没有朋友圈第二跳。

### AE — Action Exit（行动出口）
*文末是否给「在看 / 留言 / 关注」明确出口？影响涨粉转化 + 互动率。*

- **0** — 戛然而止（"就这样吧"）
- **3** — 有结尾但没引导（自然收尾）
- **5** — 给明确的行动指令 + 给读者一个回应这个指令的理由

不是「求点在看」式的乞讨，而是「如果你也有类似经历，留言告诉我」式的对话邀请。后者把读者从被动接收转成主动表达，互动率和涨粉率都跟着涨。

## Bucket 预测：阅读数为主，所有阶段统一格式 + 渐进信心标注

> 早期预测精度差是数学事实——**不通过省略 bucket 解决**，通过 **header 的 confidence 等级 + 概率分布更平**来诚实表达不确定。详见 [shared-references/prediction-anatomy.md](../shared-references/prediction-anatomy.md) 和 [state-management.md 的 confidence 表](../shared-references/state-management.md)。
>
> calibration_samples 少时，概率分布**应该更平**（如 30/30/20/15/5 而非 5/40/45/8/2）——**这是诚实表达不确定的方式**，不是把 bucket 跳过。

### 第 1 篇：用通用默认（你还没有"上一篇"）

0 粉新公众号第一篇阅读典型分布（不含个人朋友圈扩散加权）：

| Bucket | 范围（**实际阅读数**）| 含义 | 先验概率 |
|---|---|---|---|
| 底部 | < 100 | 几乎没人看见 | 35% |
| 基础盘 | 100 - 1,000 | 朋友圈 + 订阅推送的常态 | 45% |
| 命中 | 1,000 - 10,000 | 第一次被推荐流打开 | 15% |
| 小爆 | 10,000 - 100,000 | 极罕见的零粉首爆 | 4% |
| 10万+ | > 100,000 | 微信算法异常加权 | 1% |

**第 1 篇预测时**：选一个 bucket + 写概率分布。**很可能落"基础盘"**——这是数学事实，不是你失败。

### 第 2 篇起：用比率桶

让 `baseline = 上一篇的实际阅读数`（或最近 3 篇的中位数，如果有）。

| Bucket | 倍数范围 | 含义 |
|---|---|---|
| 退步 | < 0.3 × baseline | 比上一篇明显差 |
| 持平 | 0.3 - 1 × baseline | 与上一篇同档 |
| 命中 | 1 - 3 × baseline | 中度突破 |
| 小爆 | 3 - 10 × baseline | 显著破圈 |
| 大爆 | > 10 × baseline | 量级跃迁 |

**比率桶的好处**：500 → 5000 阅读（10x） 与 5w → 50w 阅读（10x） **是同一种成就**——比率桶都标"大爆"。账号从 0 粉长到 10w 粉，bucket 边界自动跟着涨。

### 第 5 篇之后：建议固定绝对桶 + 比率桶并存

跑完 5 篇后，你的 baseline 已经从 5 个数据点稳定。`/cheat-essay-status` 会主动提示：

> 你已校准 5 篇，可以基于实际分布固定绝对 bucket 边界。
> 跑 `/cheat-essay-bump --bucket-only` 自动派生。

### N≥10 之后：可以转向 percentile 桶

校准池 ≥ 10 时，bucket 边界改用 percentile：你前 20% 的文章是"爆款"，10-20% 是"命中"，30-70% 是"基础盘"。这种方案永远自洽——不管账号多大，"top 20%" 的语义稳定。

## 辅助验证维度（**不进 composite，但复盘必看**）

主 bucket 预测阅读数，但**复盘时必须填**以下三个比率，验证 rubric 是不是抓到「真触动」：

| 比率 | 计算 | 验证什么 |
|---|---|---|
| **在看率** | 在看数 / 阅读数 | EG + IE 是不是真锐——「我朋友也会觉得我在思考好东西」 |
| **分享率** | 分享次数 / 阅读数 | QD + EG 的截图驱动力——读者愿意转发出去 |
| **涨粉率** | 涨粉数 / 阅读数 | AE + 全文综合质量——读者从一次性读者变成订阅者 |

**典型基准**（参考值，每个垂类差很大）：

| 比率 | 中等 | 优秀 | 顶级 |
|---|---|---|---|
| 在看率 | 0.5% | 1.5% | 3%+ |
| 分享率 | 1% | 3% | 8%+ |
| 涨粉率 | 0.1% | 0.5% | 1%+ |

**正例对比**：阅读 1w，在看 100（1%），分享 200（2%）——质量信号好，但流量没出圈。可能 TH 弱（标题没抓住推荐流）。

**反例对比**：阅读 10w，在看 100（0.1%），分享 50（0.05%）——量大但质差。可能标题党了（TH 高但全文兑现不够），下一篇的算法权重会降。

## Cold-start 战略（**必读，最被忽视的一段**）

cold-start 期的"预测"不是预测——是**数据采集**。理解这一点是工具是否对你有用的分水岭。

### 你的预测在前 5 篇做的是三件事

1. **建立纪律**：在看到任何数据前写下盲判断。这才是脊柱——不是数字本身
2. **记录 7 维评分**：复盘后每条样本变成一个 (打分, 实绩) 配对，第 5 篇时这些配对是 rubric 第一次升级的输入
3. **记录锚点假设**：写下"我押 IE=5 比 IE=3 在看率高"这样的假设，复盘验证 → rubric 升级的证据

**你不应该做的事**：基于 cold-start 期的 composite 决定要不要发某篇稿子。**精度 ±50%——决策没意义**。已经决定要发的，跑完整循环；正在犹豫要不要发的，靠你自己感觉。

### 前 5 篇的取样策略：**主动选差异最大的稿子**

如果你前 5 篇都是 `TH=5 / IE=2 / EG=5` 的同款，复盘时**你无法**告诉哪个维度真的预测了流量——多重共线性。

**反直觉但正确的做法**：cold-start 期主动选维度组合差异最大的样本：
- 1 篇 IE 主导（议题锋度高，EG 一般）
- 1 篇 EG 主导（情感颗粒细腻，IE 平和）
- 1 篇 QD 主导（金句密集，议题中等）
- 1 篇 TH 主导（标题极强但内容平平——测试纯钩子）
- 1 篇综合中等（all 3-4）

如果你只有"安全的同款稿"，挑差异最大的 5 个。**稳定期再追求"全发爆款"，cold-start 期追求"信息量最大"**。

### 何时开始相信预测

| 校准样本 | 你能相信什么 |
|---|---|
| N=0-2 | 啥都别信。bucket 是占位 |
| N=3-5 | 相信"哪个维度可能重要"的方向；不信具体 composite 数字 |
| N=5-10 | 相信 bucket 排序；不信中枢点估计 |
| N=10-20 | 中枢可信 ±30%；可作为决策参考之一 |
| N≥20 | rubric 真正成为"作弊器"——但你也已经摸到自己的内容直觉了 |

**cold-start 真正的礼物不是预测精度——是它强迫你建立的复盘习惯**。这个习惯持续到 N=20 时，你的内容直觉本身就强很多了。

## Cold-start 期的复盘纪律（**比稳定期更严**）

前 5 篇每篇必走完整循环。**任何一篇跳过复盘 → 整个校准失败**。

每次复盘必须填的最少信息（详见 [DECISIONS.md §5 复盘必填数据集](../DECISIONS.md)）：

- 阅读数（总）
- 在看数 + 点赞数
- 分享次数
- 涨粉数（24h 或 48h）
- 完读率（如后台显示）
- Top 20 评论 + 赞数（看读者真实的接收点）
- 我的 v0 预测 vs 实际：哪个维度被验证 / 推翻

5 篇之后你会看到至少一个 pattern——比如"我的 TH 总是高估"或"我的 EG 维度根本不预测分享"——这个 pattern 是你第一次 bump 的证据。

## 第 6 篇起的升级选项

跑完 5 篇校准后，你有 3 条路：

### 路径 A：从 v0 → v1（自己拟合权重）
跑 `/cheat-essay-bump --propose "<你的具体权重调整>"`。系统会强制全量重打 + 跨模型审核。

### 路径 B：直接采纳通用版作为起点
把 [wechat-essay.md](wechat-essay.md) 的完整版公式抄到你的 `rubric_notes.md`，**然后跑 `/cheat-essay-bump`**——bump 流程会用你的 5 篇数据验证完整版在你账号上是否真的更优。

### 路径 C：保持 v0 等权，跑更多样本
如果 5 篇还看不出明显 pattern，再跑 5 篇。等权的 v0 在 10-15 个样本之前都不丢人。

---

## 这份 rubric 不能做的事

- **不能告诉你"会不会爆"**——cold-start 期的预测置信度低，bucket 通常应给 30%-50% 而非 ≥80%
- **不能替你设 bucket 边界**——账号 / 垂类差异太大
- **不能跨账号迁移**——同一份 v0 rubric 在情感号和财经号拟合出的 v1 不一样
- **不能预测 10w+**——10w+ 受微信推荐算法的非线性放大主导，单凭 rubric 内容信号无法预测。10w+ 是 rubric 命中 + 算法运气的乘积

---

## 最重要的一句话

**前 5 篇你不是在做决策，你是在收集数据。**

cold-start 期最大的诱惑是"看着 composite 8.4 就觉得这篇会爆"。**别信**。8.4 是相对一份还没校准过的 rubric 算的——它对你的账号几乎没意义。第 5 篇之后再开始相信数字。
