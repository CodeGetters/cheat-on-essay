# Starter Rubric：微信公众号文章 — 通用经验版（建议起点）

适用于做长图文公众号（1k-3k 字典型篇幅）的作者——**议题 / 角度 / 文字本身是产品**，排版和配图只是载体。

## 适用范围（**必读 — 与 wechat-essay-zero.md 一致**）

✅ **完全适用**：议题评论 / 时事观点 / 行业分析 / 个人深度随笔 / 知识科普长文 / 现象级议题讨论

⚠️ **部分适用**：教程实操类（IE 维度建议标 N/A）/ 新闻热点类（rubric 抓不到时效+大号粉丝盘+推荐流加权三个外部因素，分数与实际表现无强相关）

❌ **不适用**：< 500 字短消息卡片 / 图集漫画为主文字辅助 / 纯营销带货软文

详细解释见 [wechat-essay-zero.md](wechat-essay-zero.md) 的「适用范围」段。

## 通用经验综合分公式

```
composite = (TH×1.5 + OP×1.2 + IE×1.5 + EG×1.2 + SR + QD + AE) / 8.4 × 2.0
```

每个维度 0-5 整数分。综合分范围 0-10。

权重设定理由（**这些权重是凭通用经验设定的，不是回归拟合**）：

- **TH ×1.5**：标题决定打开率（平台权重 40%），公众号最重要的单一信号
- **IE ×1.5**：议题锋度决定互动率（30%）+ 是否值得「在看」社交背书
- **OP ×1.2**：开头留人决定完读率前段，公众号「上滑就走」无成本，开头不抓人 = 后面全废
- **EG ×1.2**：情感颗粒决定分享率（20%）—「啊我也是」的细节是朋友圈传播的核心
- **SR / QD / AE ×1.0**：辅助维度，影响完读率底层 / 二次传播 / 涨粉转化

## 7 个维度

### TH — Title Hook（标题钩子力，权重 ×1.5）
*看到标题（搜一搜 / 推荐流 / 订阅卡片 / 朋友圈分享）想不想点？决定 40% 打开率。*

- **0** — 描述性流水标题（"今天发生了一件事"）
- **3** — 有具体信息密度但平淡（"我和父亲的一次对话"）
- **5** — 指名道姓的痛点 / 反直觉断言 / 不打开就好奇死你的钩子

5/5 anchor：「你不是社恐，你只是被错配在了一个不属于你的语境里」（命名 + 反主流 + 自我识别）。
0 分对照：「我的周记 - 2026 年 5 月第二周」。

**坑**：好标题 ≠ 标题党。标题党承诺收益但不兑现，会摧毁完读率和涨粉。**TH=5 必须配 OP/EG 兑现，否则下次推荐流权重会降**。

### OP — Opening Pull（开头留人，权重 ×1.2）
*前 200 字（约 3-5 段）有没有按住读者？决定完读率前段（10% 权重）。*

- **0** — 三段铺垫还没进正题（"今天我想跟大家聊聊..." × 3 段）
- **3** — 第二段开始进入正题，但前面有"今日金句 / 长情致谢"之类的铺垫
- **5** — 第一段就有钩子 / 反差 / 具体场景，让读者忘记自己在「读公众号」

5/5 anchor：开篇一个具体的对话场景或感官画面，三句话内让读者完全沉入，铺垫为零。
0 分对照：「最近天气转凉了，我又一次想起了那件事。说起来要从三年前开始讲起…」（典型的"温度+回忆+预告"三件套铺垫）。

### IE — Issue Edge（议题锋度，权重 ×1.5）
*角度是不是常见到平庸，或锋利到值得「在看」？决定互动率（30% 权重）。*

- **0** — 常识复读（"努力就有回报"、"要平衡工作和生活"）
- **3** — 有自己的切入但角度大众化（"我觉得职场要主动沟通"）
- **5** — 反主流共识 / 命名了读者意识到但说不出的现象 / 把熟悉的东西陌生化

5/5 anchor：把"职场 35 岁危机"重新框架为"组织对个体可替代性的工业化定价机制"。
0 分对照：「努力就有收获」。

「在看」按钮是社交风险投资——读者只在「想让朋友知道我在思考这个」时才点。IE 是这个动作的核心驱动。

### EG — Emotional Granularity（情感颗粒，权重 ×1.2）
*有没有具体到读者「啊我也是」的细节？决定分享率（20% 权重）。*

- **0** — 抽象情绪词堆砌（"焦虑"、"内耗"、"破防"）
- **3** — 一两个具体场景但快速带过
- **5** — 颗粒度极细（具体物品、时间、对话），细到读者觉得「这是写我的吗？」

5/5 anchor：「凌晨三点，我第十一次刷新他的微信朋友圈，发现签名变了，但封面图没变」。
0 分对照：「那段时间我很焦虑」。

分享到朋友圈本质是「这文字代表我」。颗粒度不足 = 没有代入感 = 没人转发。

### SR — Structural Rhythm（结构节奏，权重 ×1.0）
*小标题、加粗、段落呼吸如何？影响完读率全程（10% 权重底层）。*

- **0** — 整篇没有小标题 / 加粗 / 列表，3000 字砌墙
- **3** — 有小标题但分段密度不均（前面密、后面散）
- **5** — 节奏可视化：小标题清晰 / 关键信息加粗 / 长段拆短 / 视觉留白

手机阅读场景下，结构 = 完读率。砌墙 = 跳出。

**经验法则**：长文章每 400 字左右一个小标题或视觉切换点；关键论点首句加粗；超过 5 行的段落强制拆分。

### QD — Quote Density（金句密度，权重 ×1.0）
*是否有可截图分享到朋友圈 / 微信群的句子？影响二次传播。*

- **0** — 全文找不到截图点（叙事流水）
- **3** — 全文有 1 句能独立站立
- **5** — 每千字 ≥2 个截图句，分布在不同段位（开头 / 中间 / 结尾）

5/5 anchor 的金句具备三个特征：① 离开上下文还能站立 ② 12-25 字内 ③ 命名了一个具体现象。

**校准 caveat**：QD 高但 EG 低的文章会出现「金句很漂亮但读完没记住人」——读者截图传播一两次后就忘了。健康的金句必须从 EG 的具体场景里生长出来，不是脱离上下文的金句堆砌。

### AE — Action Exit（行动出口，权重 ×1.0）
*文末是否给「在看 / 留言 / 关注」明确出口？影响涨粉转化 + 互动率。*

- **0** — 戛然而止（"就这样吧"）
- **3** — 有结尾但没引导（自然收尾）
- **5** — 给明确的行动指令 + 给读者一个回应这个指令的理由

5/5 anchor：「如果你也曾在凌晨三点删除过一段对话，留言告诉我那段对话的最后一句话——我们一起把它们埋好」（对话邀请 + 共同仪式）。
0 分对照：「好了，今天就先写到这里」。

**坑**：不是「求点在看」式的乞讨，而是「如果你也有类似经历」式的对话邀请。后者把读者从被动接收转成主动表达，互动率和涨粉率都跟着涨。

## 辅助验证维度（不进 composite，复盘必看）

| 比率 | 计算 | 验证什么 |
|---|---|---|
| **在看率** | 在看数 / 阅读数 | EG + IE 是不是真锐 |
| **分享率** | 分享次数 / 阅读数 | QD + EG 的截图驱动力 |
| **涨粉率** | 涨粉数 / 阅读数 | AE + 全文综合质量 |

典型基准（参考值，每个垂类差很大）：

| 比率 | 中等 | 优秀 | 顶级 |
|---|---|---|---|
| 在看率 | 0.5% | 1.5% | 3%+ |
| 分享率 | 1% | 3% | 8%+ |
| 涨粉率 | 0.1% | 0.5% | 1%+ |

---

## 反 pattern（必须主动识别 + 在打分时 -1 调整）

- **标题党**：TH=5 但 OP/EG ≤ 2 → TH 实际打 3，下次推荐权重会被算法压
- **抒情砌墙**：EG=5 但 SR ≤ 2（3000 字无小标题） → 手机端跳出严重，实际 EG 价值打折
- **金句脱离**：QD=5 但 EG ≤ 2 → 截图传播一两次就忘记作者，AE 价值归零
- **议题悬空**：IE=5 但 EG ≤ 2 → 「这个角度很对但读完没共鸣」，分享率上不去
- **结尾失声**：通篇好但 AE=0 → 涨粉率显著低于阅读量预期

复盘时如果某篇 composite 高但实际表现差，**优先检查这五个反 pattern 是不是命中了**。

## 校准 caveat 与未来版本预告

以下观察来自方法论推导，**等待真实数据验证 / 推翻**：

- **QD vs EG 部分冗余**：高 QD 的文章往往也 EG 高——可能是同一种"具体性"能力的不同侧面。未来 v1.1 候选会考虑合并
- **TH 的权重可能被高估**：1.5 权重是基于「打开率 40% 算法权重」推导，但 TH=5 配 OP/EG 低的"标题党"会触发算法惩罚——实际权重可能 ≤ 1.3
- **垂类敏感性**：财经号 / 情感号 / 时评号 / 职场号的真实权重差异可能很大。第一次 bump 后大概率会出现「我的账号 IE 权重应该 ×2.0 而不是 ×1.5」之类的修正

跑完 5 篇后用 `/cheat-essay-bump --propose "<你的具体权重调整>"` 验证。

## 这份 rubric 不能做的事

- **不能告诉你"会不会爆"**——10w+ 受微信推荐算法非线性放大主导，单凭 rubric 内容信号无法预测
- **不能跨账号迁移**——同一份通用版在情感号和财经号拟合出的 v1 不一样
- **不能取代你的内容直觉**——rubric 是辅助判断，不是判断本身。当你的直觉强烈否定一个 composite 8.5 的稿子时，相信直觉，复盘时把它记下来
