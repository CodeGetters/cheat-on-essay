# 样本校准：用 wechat-essay-zero.md 给 5 篇真实公众号文章打分

**目的**：用现行 v0 等权 rubric 给 5 篇真实样本打分，反检维度定义是否能区分这些文章、锚点描述是否准确、有无要增减的维度。

**这不是预测**——这 5 篇都已发布，纯粹用于 rubric 内部校准。

**抓取方式**：CDP（Chrome remote-debugging-port=9222）+ `Runtime.evaluate` 抽 `#js_content` 正文。无后台数据，仅基于内容打分。

## 逐篇打分

### #1《宇树载人机甲发布》（APPSO，新闻热点）

| 维度 | 分 | 理由 |
|---|---|---|
| **TH** 标题钩子力 | 4 | "390 万起"+ "刚刚"双钩子：价格冲击 + 时效性，缺一个"人物 / 反主流"维度上不了 5 |
| **OP** 开头留人 | 4 | "《铁甲钢拳》《机动战士高达》里的铁疙瘩，终于从二次元杀进现实了"——影视类比 + 反差，第一句就钩住 |
| **IE** 议题锋度 | 2 | 角度是描述性的（"这个产品多酷"），无反主流断言 / 结构性观察 |
| **EG** 情感颗粒 | 2 | 颗粒主要是产品参数 + 影视类比，没有"我也是"的私人代入 |
| **SR** 结构节奏 | 3 | 没有显式小标题但段落短、节奏明快，符合新闻节奏 |
| **QD** 金句密度 | 3 | "我将以高达形态出击"是高识别度截图句，但全文就这一句 |
| **AE** 行动出口 | 0 | 文末是"我们正在招募伙伴"的硬广，不是对话邀请 |
| **composite** | **2.57 × 2 = 5.14** | 中等偏下——但这类新闻通常靠时效性 + 算法推荐起量，不靠 rubric 信号 |

**观察**：rubric 给 5.14 但这种「时效新闻」可能实际跑出 10w+——因为热点 + 大号粉丝盘 + 推荐流加权。这暴露 **rubric 不预测「热点流量加成」**，需要在文档里说明。

| 维度 | 分 | 理由 |
|---|---|---|

| **OP** | 5 | 开篇三句话："人类花了半个世纪把文档从打字机搬到 Word，又花了二十年搬到云端。结果 AI 时代真正的通用格式，是一门 2004 年发明的纯文本语言—— Markdown" ——历史尺度 + 反讽 + 立刻进入主题，0 铺垫 |
| **IE** | 4 | 议题锋度高（挑战主流共识 "Markdown 是 AI 时代 Word"），但没真正反主流（最终结论是"HTML 不会取代 Markdown"），偏向「平衡的洞察」而非「锋利的判断」 |
| **EG** | 2 | 纯技术议题，颗粒主要是产品名 / 技术参数，无个人化场景 |
| **SR** | 5 | 节奏极佳：4 个二级小标题（"Markdown 为什么最适合 AI"/"为什么不是 PDF、Word、PPT"/"Markdown 也要过时了？"），关键句加粗、有图、段落呼吸到位 |
| **QD** | 4 | 多个可截图句："但真正活下来的，从来不是界面，是协议"/"它不会被取代，只会被遗忘。而在技术的世界里，被所有人遗忘，恰恰是一种格式最终胜利的方式"——金句质量高且分布在结尾 |
| **AE** | 0 | 同样是「我们正在招募伙伴」硬广收尾，无对话邀请 |

**观察**：QD 集中在结尾段，开头中间偏少——能不能区分「金句集中型」vs「金句分散型」？目前 QD 定义说"分布在不同段位"，本篇结尾密集开头少，按当前定义应该是 3 分而不是 4 分。**维度定义和实际打分的张力暴露 v0 的 QD 锚点需要更精确**。

## 校准发现总结

### 🔴 必须修复（v0.1.0 内）

1. **rubric 适用范围声明缺失**：v0 隐含假设是"中长篇议题/观点文章"，但样本里 5 篇有 3 种形态——新闻热点（#1）/ 深度议题（#2#4）/ 教程实操（#3）/ 短消息（#5）。rubric 必须在 README 和 starter-rubric 顶部明确：「本 rubric 适用于 1k-5k 字的议题/观点/深度文章；新闻热点和短消息形态信号驱动因素不同，不在适用范围」。

2. **IE 维度对教程类不适用**：#3 暴露 IE 强行打分会失真。两种解决方案：
   - A) starter-rubric 增加适用范围筛选，让用户在 init 时选「议题/观点」vs「教程/实操」，对应不同维度组合
   - B) 把 IE 替换为更通用的「**论点强度**」维度（议题文 = 议题锋度；教程文 = 实操密度），但定义会变模糊

3. **AE 标准模板压平打分**：#3 #4 都用了完全相同的「三连模板」（点赞+在看+转发+星标），都打 5。这表明 AE 在头部账号已被「标准化套路」覆盖——区分度不足。**新维度提议**：AE 拆成「行动出口强度」（标准模板 vs 对话邀请 vs 共同仪式）。

### 🟡 应该修复（v0.2.0 候选）

4. **QD 锚点要更精确**：「每千字 ≥2 个截图句」+「分布在不同段位」两个条件目前 OR 还是 AND 不明确。#2 满足分布但密度偏低，#4 都满足——锚点应改为：「**密度** 每千字 ≥ X 句 **AND** **分布** 至少 3 个段位有金句」。

5. **缺「热点借势力」维度**：#1 这种新闻文章靠时效性 + 算法推荐流，rubric 7 维抓不到。**候选新维度 HM**（Hot-topic Momentum）：是否在热点峰值 24h 内发布、是否抢到首发位、是否包含可索引关键词。但只在该频道做新闻类时启用。

6. **缺「人格信号」维度**：#3 #4 都是卡兹克本人，文末标准三连 + 行文风格高度一致——读者跟的是「人」而不是「文」。**候选新维度 PI**（Personal Identity）：作者在文中是否暴露足够强的身份信号让读者识别 / 追随。情感号 / 知识号场景这个维度可能比 IE 还重要。

### 🟢 整体良好

- 7 维体系区分度尚可：composite 范围 2.66（#5 失效）到 8.28（#4 高），有合理梯度
- 1-5 分锚点对议题/观点类样本（#2 #4）可用
- 反 pattern 段（standard 7 维之外）有现实指导意义——#1 #3 都触发了「AE 标准模板」反 pattern
